# МосУ МВД: 36 интерактивных графиков и HTML-отчёт

Учебный проект по анализу CSV канала **МосУ МВД России имени В. Я. Кикотя**: 36 графиков, 11 таблиц, фильтры и автономный HTML.

[![Открыть в Google Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/lirik4747/telegram-analysis/blob/main/telegram_analysis.ipynb)

## Запуск одной ячейкой

1. Нажмите **Открыть в Google Colab**.
2. Выберите **Среда выполнения → Выполнить все**. CSV загрузится автоматически с проверкой SHA-256. GPU не требуется.
3. **Все 36 графиков и 11 таблиц появятся прямо под ячейкой.** В отчёте по умолчанию выбраны «Все разделы». Скачивание не требуется.
4. Используйте разделы и поиск внутри отчёта. Чтобы изменить даты, единицу анализа или содержание, настройте фильтры над отчётом и нажмите **Обновить**.
5. **Открыть HTML-отчёт** повторно показывает весь отчёт внутри Colab с текущими фильтрами.
6. **Скачать HTML** сохраняет автономную копию. **Экспорт PNG + HTML + CSV** скачивает ZIP со всеми графиками, таблицами и методикой.

Если предпочитаете вставить код вручную, целиком скопируйте [telegram_analysis.py](telegram_analysis.py) в одну ячейку Colab и запустите. Свой CSV можно заранее положить в `/content/Messages_МосУ_МВД_России_имени_В_Я_Кикотя.csv`.

Графики работают в изолированном HTML-документе прямо внутри вывода ноутбука, без локального HTTP-сервера. Данные для просмотра и Plotly включены в отчёт. Виджеты используются для фильтров и кнопок; графики выводятся отдельно от `ipywidgets.Output`.

## Данные и ограничения

- Источник — предоставленный CSV; внешние сообщения не запрашиваются. Период: 13.02.2025–06.04.2026. Часовой пояс: **Europe/Moscow**.
- 1 915 строк содержат `MediaMessage`. Одна строка не обязательно равна самостоятельной публикации: она может быть частью медиагруппы. Маркер не различает фото и видео.
- Режим «Группы по времени» объединяет строки одного канала с одинаковым временем UTC. Это эвристика: ID альбома в CSV нет. Счётчики берутся по максимуму, а не суммируются.
- Пустые комментарии неизвестны, ноль — известное значение. Просмотры не считаются уникальным охватом.
- Число подписчиков везде равно 2 829; график исторического роста по этой колонке не строится.
- Счётчики накопленные, время измерения не указано. Старые и новые записи имеют разный возраст; сравнения описательные.
- Реакций на 100 просмотров = 100 × сумма реакций / сумма просмотров по единицам с обеими известными метриками и просмотрами > 0.
- Крайние месяцы могут быть неполными. Нули активности означают отсутствие записей в выгрузке.
- В корреляциях используются полные наблюдения каждой пары. При постоянном признаке или n < 3 коэффициент не рассчитывается. Корреляция не доказывает причинность.
- Слова считаются по числу текстов с термином, без лемматизации; при равных частотах порядок алфавитный.

SHA-256 исходного CSV: `cd5b84c3e47fa3c2d0c206e5ec3c35bca96352556bfcdcd0f2471e4037179846`.
