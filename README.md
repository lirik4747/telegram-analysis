# Анализ Telegram-канала

Учебный проект по анализу выгрузки канала **МосУ МВД России имени В. Я. Кикотя**.

[![Открыть в Google Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/lirik4747/telegram-analysis/blob/main/telegram_analysis.ipynb)

## Файлы

- [telegram_analysis.ipynb](telegram_analysis.ipynb) — готовый ноутбук Google Colab.
- [telegram_analysis.py](telegram_analysis.py) — весь код для одной ячейки Colab.
- [Messages_МосУ_МВД_России_имени_В_Я_Кикотя.csv](Messages_МосУ_МВД_России_имени_В_Я_Кикотя.csv) — полная исходная база, 2 324 строки.
- [requirements.txt](requirements.txt) — зависимости Python.

## Запуск

1. Нажмите **Открыть в Google Colab**.
2. Выберите **Среда выполнения → Выполнить все**. Ноутбук автоматически скачает CSV из этого репозитория.
3. Выберите даты, единицу анализа и раздел панели; нажмите **Обновить**.
4. Кнопка **Экспорт PNG + HTML + CSV** скачивает ZIP с графиками, таблицами и методикой.

GPU не требуется. Для Python-файла вместо ноутбука загрузите CSV вручную в `/content`, затем вставьте код в ячейку Colab.

## Что исследуется

Активность по дням и месяцам; распределение публикаций по дням недели и часам; просмотры и их разброс; реакции; связь просмотров с реакциями и длиной текста; частые слова и хештеги; полнота данных. Есть таблицы лидеров по просмотрам и реакциям на 100 просмотров.

## Данные и ограничения

- Источник — предоставленный CSV; внешние сообщения не запрашиваются.
- Период выгрузки: 13.02.2025–06.04.2026. На графиках используется **Europe/Moscow**.
- 1 915 строк содержат `MediaMessage`. Одна строка не обязательно равна самостоятельной публикации: она может быть частью медиагруппы.
- Группировка по точному времени — отдельный эвристический режим. Идентификатора альбома в CSV нет.
- Пустые комментарии не заменяются нулями; просмотры не считаются уникальным охватом.
- Значение числа подписчиков везде равно 2 829; исторический рост подписчиков по нему не оценивается.
- Счётчики накопленные, время их измерения не указано; старые и новые записи разного возраста.
- Корреляции описательные и не доказывают причинность.
